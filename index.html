사용 가능한 기능

입력값이 2개 이상 필요한 기능은 입력값2·입력값3 열까지 함께 입력해야 결과가 계산됩니다. 필요한 입력값 개수는 기능마다 달라서, 그보다 많은 열은 화면에 표시되지 않습니다. 입력값2·입력값3은 보통 모든 행에 같은 값을 쓰므로, 1행에 입력하면 아래 행까지 자동으로 채워지고 필요하면 행마다 다시 수정할 수 있습니다.

🔍 조회 참조표 (XLOOKUP·COUNTIF·SUMIF 공용 데이터)📌 화면 분할 모드

아래 표의 아무 칸이나 클릭한 뒤 엑셀에서 복사한 범위를 그대로 붙여넣으세요(Ctrl+V). 각 열 맨 위에 1열, 2열, 3열… 번호가 표시됩니다.
XLOOKUP은 VLOOKUP과 달리 기준이 되는 값이 있는 열이 꼭 맨 왼쪽일 필요가 없으므로, 필요한 열들을 포함해서 자유롭게 범위를 복사하면 됩니다(예: [사번, 이름, 부서]에서 이름으로 사번을 찾으려면 왼쪽값 열번호 2, 찾을 값 열번호 1).
열 번호 대신 "1행은 제목행"을 체크하면 1행의 열 이름(예: 부서)을 그대로 열 지정에 쓸 수 있습니다.

💡 엑셀에서 복사한 자료를 아래 표 아무 칸에나 붙여넣으세요(Ctrl+V) — 붙여넣으면 행이 자동으로 늘어납니다.

📊 피벗 테이블

위 참조표 데이터를 기준으로 그룹별 집계표를 만듭니다. 행 그룹(표의 세로쪽 구분)에 고른 열의 값마다 표의 세로 방향으로 한 행씩 묶고, 열 그룹(표의 가로쪽 구분)을 고르면 그 값마다 표의 가로 방향으로 열을 나눠 교차표를 만듭니다(고르지 않으면 값 하나만 계산). 값 열은 합계·평균을 낼 대상 열이고, 개수만 셀 때는 아무 열이나 선택해도 됩니다.

행 그룹(표의 세로쪽 구분) 열 그룹(표의 가로쪽 구분, 선택) 값 열 집계 방식

🔢 조건부 집계

조건범위(조건을 확인할 열)를 고르고, 조건 방식(🔁 자기 값 기준 계산·정확히 일치·이상·이하·중간범위·글자 포함·글자 포함 안 함·개수·합계)을 선택한 뒤 옆 칸에 기준값을 입력하세요(이 기준값이 엑셀 COUNTIF·SUMIF의 "조건"에 해당합니다). SUMIF·SUMIFS는 합계범위(더할 값이 있는 열)도 추가로 고릅니다. "중간(범위)"는 최소~최대 두 값을 입력하고, "개수"·"합계"는 값 입력 없이 그 열에 값이 있는 행을 전부 포함합니다. "🔁 자기 값 기준 계산"을 고르면 값 입력 없이, COUNTIF는 실제 엑셀 =COUNTIF(F:F,F2)처럼 그 열의 각 행이 같은 값을 몇 번 가지는지, SUMIF는 =SUMIF(F:F,F2,합계범위)처럼 같은 값을 가진 행들의 합계범위 값을 행마다 계산합니다.

🔀 텍스트 나누기

참조표에서 나눌 열과 구분자를 고르고 나누면, 그 열의 값을 전부 쪼개서 조각 개수만큼 참조표 오른쪽에 새 열이 생기고 각 조각이 나뉘어 들어갑니다.

🔗 텍스트 합치기

합칠 열을 순서대로 고르세요. 열과 열 사이마다 서로 다른 연결글자를 따로 입력할 수 있습니다(비워두면 그냥 붙습니다). 합치면 참조표 오른쪽에 합쳐진 값이 새 열로 추가됩니다.

🏅 심사표 계산

참조표에 심사위원별 점수를 열마다 하나씩 붙여넣은 뒤, 점수 시작 열과 점수 끝 열을 고르고 계산하면 행마다 최고점 1개·최저점 1개를 뺀 나머지 점수의 합계가 참조표 오른쪽에 새 열로 추가됩니다.

🔗 동적 목록 구현

참조표 1열부터 단계별로 실제 값을 입력하세요(예: 1열 충청남도, 2열 부여군, 3열 부여읍 — 최대 8단계). "엑셀 파일로 다운로드"를 누르면 동적목록.xlsx 파일이 만들어집니다. 파일의 "동적목록입력" 시트 2행부터(500행까지 준비됨) 칸을 클릭하면 ▼ 드롭다운이 나타나며, 1열부터 순서대로 고르면 앞선 선택에 맞춰 다음 열 목록이 자동으로 바뀝니다. "목록데이터" 시트는 참고용 원본 데이터라 직접 수정할 필요 없습니다.

🔓 통합된 셀 해제하기

엑셀에서 병합된 셀을 그대로 복사해 붙여넣으면 병합됐던 칸은 첫 줄에만 값이 있고 나머지는 빈 칸으로 들어옵니다(브라우저에서는 병합된 모양 그대로 붙여넣을 방법이 없어서, 병합 해제 전과 같은 형태로 정리하는 방식입니다). 버튼을 누르면 참조표의 모든 열을 한 번에 검사해서, 빈 칸을 바로 위 값으로 채웁니다.

📷 사진파일 일괄 입력

폴더를 선택하면 사진 파일들을 파일명 순서대로 1열=파일명 · 2열=사진 행으로 넣고, 사이사이 빈 행을 하나씩 끼워 넣습니다.
· 셀에 채우기: 사진 비율에 맞는 칸 크기로 시작하고, 이후 행 높이·열 너비를 같이 늘리면 사진도 따라서 커집니다.
· 원본 비율 유지: "사진 칸 크기(px)"에 입력한 크기로 고정되어 삽입됩니다(이후 셀 크기를 바꿔도 사진 크기는 그대로).
📏 셀의 현재 픽셀 크기는 열/행 경계선을 클릭한 채 살짝 드래그하면 "너비: 8.43(64 픽셀)"처럼 바로 표시됩니다.
